## 🧠 About The Project

Most marketing calculators use static, linear projections (e.g., *"If $100 gets 10 leads, then $10,000 gets 1,000 leads"*). In the real world, this logic fails due to channel saturation, audience fatigue, and platform learning phases.

This application solves that problem by applying continuous-curve calculus to marketing budget allocation. Using the `scipy.optimize` SLSQP algorithm, it calculates the exact mathematical point of diminishing returns for every channel in a marketing mix, automatically shifting budget to minimize Blended CAC. 

It also features a live **AI Strategic Advisor** (powered by Gemini 2.5 Flash) that actively reads the generated optimization matrix to provide context-aware, Fortune-500 level scaling advice.

### ✨ Key Features
* **Non-Linear Optimization Engine:** Automatically minimizes Blended CAC by reallocating budget based on historical performance boundaries.
* **Intelligent Curve Assignment:** Auto-detects channel types (e.g., "Search", "Social", "Email") and assigns the correct mathematical saturation model.
* **Interactive AI Copilot:** A built-in Google Gemini agent that reads the live Pandas DataFrame to offer data-driven strategy.
* **Dynamic Visualizations:** Sleek, borderless Plotly donut charts and interactive line graphs tracking marginal return drop-offs.
* **Premium Cyberpunk UI:** Custom Synthwave CSS styling, frosted glass pop-ups, and neon typography for a polished SaaS feel.

## 🧮 The 5 Mathematical Archetypes

The engine supports five distinct continuous-curve models, allowing it to mimic real-world consumer behavior across different mediums:

1. **Logarithmic (Search / Retargeting):** High initial intent means the first dollar is highly efficient, but it hits a hard saturation ceiling rapidly as search volume exhausts.
2. **Hill Function / S-Curve (Paid Social):** Starts slow during the algorithm's "learning phase", hits a hyper-efficient scaling period, and eventually flattens due to creative fatigue.
3. **Negative Exponential (Email / SMS):** Scales linearly out of the gate until it hits the absolute limit of your existing database/audience size.
4. **Power Law (SEO / Content):** Diminishes very slowly and compounds over time without a rigid ceiling.
5. **Shifted Sigmoid (Events / PR):** Yields zero results until a massive minimum entry cost (e.g., a trade show sponsorship) is crossed.
